# Page Accent 隐私政策

最后更新：2026 年 7 月 11 日

Page Accent 是网页颜色标识线扩展。Page Accent 的单一用途是帮助用户按匹配规则为网站添加彩色标识线，从而一眼区分不同页面。

## 我们处理的数据

Page Accent 会在用户的浏览器本地处理和保存以下数据：

- 扩展设置，例如主题、线条位置、线条粗细、角标显示和标签组同步设置。
- 用户主动创建的颜色标记，包括被标记页面的 URL、页面标题、颜色和相关状态。
- 用户主动创建的本地匹配规则，例如网站域名、路径关键词或 URL 特征。
- 为了显示颜色标记和匹配本地规则而读取的当前页面 URL 和标题。

这些数据用于在页面刷新、标签切换或浏览器重启后恢复用户设置和颜色标记。

## 数据存储与传输

Page Accent 不提供账号系统，也不提供远程同步服务。上述数据默认保存在用户自己的浏览器本地存储中。

Page Accent 不会将用户的标记数据、浏览记录、页面标题、URL、规则或设置上传到开发者服务器。Page Accent 不出售用户数据，也不会为了广告、画像、信用评估或与扩展单一用途无关的目的向第三方转移用户数据。

## 权限使用说明

Page Accent 仅为实现网站颜色标识线功能请求必要权限：

- `activeTab`：在用户打开弹窗、使用快捷键或右键菜单操作时，读取当前活动标签页的信息并应用用户选择的颜色标记。
- `storage`：在浏览器本地保存扩展设置、颜色标记和匹配规则。
- `tabs`：查询和监听标签页切换、更新状态，并在用户从侧边栏选择已标记页面时打开对应标签页。
- `contextMenus`：在右键菜单中提供设置颜色、移除颜色和创建规则等用户主动触发的操作。
- `sidePanel`：提供侧边栏界面，用于查看当前页面状态、已保存页面标记和本地规则。
- `tabGroups`：在用户启用标签组同步时读取浏览器标签组颜色，并让未单独标记的标签页使用对应标签组颜色。
- 主机权限：在用户访问的 http 和 https 页面上运行扩展包内的内容脚本，用于显示本地颜色边线、角标，并根据当前页面 URL 和标题匹配本地规则。

Page Accent 不使用远程 JavaScript 或远程 Wasm。所有脚本和资源均包含在扩展程序软件包中。

## 数据保留与删除

Page Accent 的数据保存在用户浏览器本地。用户可以通过扩展设置、浏览器扩展管理页面或浏览器站点数据/扩展数据管理功能清除相关数据。卸载 Page Accent 后，浏览器通常会删除该扩展保存的本地数据。

## 儿童隐私

Page Accent 面向一般用户，不会主动收集儿童的个人身份信息、健康信息、财务信息、身份验证信息、个人通讯内容、精确位置或网站正文内容。

## 政策变更

如果 Page Accent 的数据处理方式发生重大变化，本隐私政策将更新，并在扩展商店页面或对应公开页面中提供最新版本。
